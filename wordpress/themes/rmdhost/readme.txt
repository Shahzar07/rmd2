Black & white hosting theme for VPS, dedicated and game-server providers. Elementor, WooCommerce and block-editor ready.

== Description ==

RMDHost is a complete hosting-company theme: animated homepage, 12 server product
landing pages with plan boxes (CPU · RAM · Storage · Bandwidth · Location · DDoS ·
Price · More details · Order now), mega menu with promo panels, GBP/USD switcher,
light/dark mode, data-centre map, network status, knowledge base, tutorials, FAQ,
support/contact page, blog and a GDPR cookie banner.

Every section is a template part, so the same markup is used by the theme templates,
the RMDHost Elementor widgets, the "RMDHost section" block and the
[rmdhost_section] shortcode (provided by the RMDHost Core plugin).

= Compatibility =

* Elementor & Elementor Pro (widgets, theme locations for header/footer builder)
* WooCommerce (shop, product, cart, checkout and account styling, header mini-cart,
  server specs on products, optional "sell plans with WooCommerce" mode)
* Block editor (editor styles, wide/full alignment, block patterns)
* Yoast SEO, Rank Math, SEOPress, All in One SEO, The SEO Framework (built-in SEO
  meta/schema switches off automatically)
* Translation ready (languages/rmdhost.pot), RTL-safe logical layout

== Installation ==

1. Appearance → Themes → Add New → Upload Theme → choose rmdhost.zip → Activate.
2. Install the recommended plugins from the notice (RMDHost Core, Elementor, WooCommerce).
3. RMDHost → Welcome & import → "Import demo content".
4. Appearance → Customize → RMDHost Theme to edit the hero, offer banner, review rating,
   stats, currency, colours, footer and cookie banner.

== Frequently Asked Questions ==

= Where do I change plans and prices? =
RMDHost → Server plans (with RMDHost Core). Assign each plan to a Product group.
Without the plugin the bundled catalogue in inc/data/catalog.json is used.

= Can I build pages with Elementor? =
Yes. Every section is available as an Elementor widget in the "RMDHost" category.

= Can I sell plans with WooCommerce? =
Yes. Customize → RMDHost Theme → Store → "Plan boxes use: WooCommerce products".
