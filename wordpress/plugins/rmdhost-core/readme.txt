Companion plugin for the RMDHost theme.

== Description ==

* Server plans, Locations, Reviews and FAQs as editable content types (RMDHost menu).
  Anything you add replaces the theme's built-in list for that type.
* 30 Elementor widgets – one per theme section – with every text, list, link and image editable.
* "RMDHost section" block with a live, pixel-accurate preview, plus page patterns.
* [rmdhost_section name="pricing" groups="vps,dedicated-servers"] shortcode for any builder.
* One-click demo import: pages with templates, mega menu, footer menus, posts, plans,
  optional WooCommerce products and an Elementor homepage. Safe to run again.
* Contact form with nonce, honeypot and rate limit; messages are emailed and stored
  under RMDHost → Messages.
